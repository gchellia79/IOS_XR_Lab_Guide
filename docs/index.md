# IOS_XR_Lab_Guide

Practise accessing the dCloud lab, staging and committing IOS XR configurations, monitoring processes and memory, and configuring BGP and route policies.

The guide follows the supplied Word lab document. Credentials are replaced with placeholders; use the access details supplied for your lab session.

| No. | Chapter | Description |
| --- | --- | --- |
| 01 | [Preparation](01-preparation/index.md) | Access dCloud, start the lab, and open device consoles. |
| 02 | [Commit configuration](02-commit-configuration/index.md) | Stage changes, use commit options, and practise rollback. |
| 03 | [Operations and monitoring](03-operations-and-monitoring/index.md) | Inspect processes, memory, diagnostics, task groups, interfaces, and LPTS. |
| 04 | [BGP](04-bgp/index.md) | Establish PE-CE neighbors and apply route policies and prefix filters. |

!!! note
	The BGP exercises use the preconfigured lab core. This guide does not include a standalone ISIS/segment-routing chapter.

Begin with [01. Preparation](01-preparation/index.md).
